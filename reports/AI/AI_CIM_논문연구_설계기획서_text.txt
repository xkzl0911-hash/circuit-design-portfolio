연구 요약
최종 목표는 4개의 이진 특징을 받아 학습과 분류를 수행하는 트랜지스터 수준 온칩 AI 회로를 설계하고,
동일한 CMOS 공정과 데이터에서 기존 구조보다 효율적인지 검증하는 것이다. 첫 데모는 16개의 합성
데이터에 대한 로지스틱 뉴런 하나지만, 논문의 기여는 분류 정확도 숫자보다 메모리 읽기 구조, 정확도
보장 조건, 실제 에너지 비용에 있다.
연구 가설: 학습에서는 16비트 전체 정밀도를 유지하고 추론에서는 상위 8비트만 먼저 읽는다. 상위 비트의 부호 정보와 남은 비트의
상계를 이용해 최종 분류가 확정되면 하위 비트라인을 활성화하지 않는다. 이때 클래스 결과는 전체 16비트 MAC과 완전히 같아야
한다.
핵심 결론 세 가지
• ADC와 DAC가 주역이 아니다. 본 1차 칩은 이진 특징과 고정소수점 가중치를 사용하는 완전 디지털 SRAM-CIM이므로 변환기
없이 구현한다. 아날로그 CIM은 2차 비교 연구로 남긴다.
• 미분은 로그 회로가 아니다. BCE와 이상적인 Sigmoid의 합성 기울기는 (p-y)x이다. 디지털 LUT 기반 회로에서는 이 식을
surrogate gradient로 사용한다.
• 신규성은 아직 미확정이다. T-PIM의 온칩 학습과 최근의 early-termination 연구를 고려하면 구체적인 설계 차별점과 실측
결과가 필요하다.
전체 연구 절차
선행연구 · 문제 정의 → 비트 정확한 Python 기준 모델 → 8T SRAM 단일 셀 → 5×16 가중치 매크로 →
MAC/Sigmoid/SGD → 전수 학습 시뮬레이션 → 조기 종료 구조 → B0/B1/B2 공정 비교 → PVT/Monte Carlo →
Layout·DRC/LVS/PEX → 논문 작성. 각 단계가 통과되지 않으면 상위 단계 완료를 주장하지 않는다.

01 연구 가설과 선행연구
1.1 무엇이 이미 구현됐는가
KAIST의 T-PIM은 8T SRAM 셀 내부 AND, bit-serial arithmetic, sparsity handling 및 기울기·가중치 갱신
경로를 갖춘 온칩 학습용 처리 메모리를 28nm CMOS 칩으로 구현했다 [R1]. 8T SRAM의 별도 읽기 포트를 연산에
이용한다는 발상 자체는 새로운 것이 아니다.
정밀도 조절 역시 SRAM-CIM 분야에서 활발히 연구되고 있다. 2024년 ISCAS 논문은 재구성 가능한 8T SRAM
아날로그 IMC를 제시했고 [R2], 2025년 CICC 논문은 동적 weight skipping과 런타임 부분합 양자화를 제안했다
[R3].
2025~2026년에는 early termination과 적응형 비트 순서 연구가 발표됐다. BLC-CIM은 bit-level 조기 종료를
다뤘고 [R4], BitFair는 early termination/bit ordering을 활용했다 [R5]. 따라서 단순히 “8비트만 먼저 읽는다”는
설명은 논문 기여로 충분하지 않다.

signed Q4.12는 4개의 정수부 비트에 부호를 포함하는 관례로 사용해 가중치 범위는 [-8, 8)이다. 양자화·포화 규칙을

3.2 sigmoid ROM 사양
z_int를 1024 간격(실수 z의 0.25 간격)으로 가장 가까운 정수 k에 반올림하고, 범위 -32...32로 제한한 뒤 65-entry
ROM에서 P9=round(256·sigmoid(k/4))을 읽는다. ROM은 65×9=585비트에 해당한다. 256은 9비트로
표현하고 16비트 가중치 메모리보다 ROM이 클 수 있다는 점도 면적 분석에 포함한다.
 k = clip(round(z_int / 1024), -32, +32) ; P9 = ROM[k + 32]
분류는 z_int>=0 조건을 사용한다. 이는 이상적 sigmoid(z)>=0.5의 정확한 부호 판정이다. 주의: ROM 반올림 때문에
z가 0보다 조금 작아도 P9=128이 될 수 있으므로, 양자화된 P9에 0.5 임계값을 적용하는 것과 정확히 같지 않을 수
있다. 이 차이는 명시된 설계 규약이며 오류로 숨기지 않는다.
3.3 BCE와 gradient의 관계
 L = -[ y·log(p) + (1-y)·log(1-p) ]
 ideal sigmoid + BCE : ∂L/∂w_i = (p-y)·x_i
이 식은 연속적인 이상적 sigmoid와 BCE를 합성했을 때의 해석적 미분이다. 디지털 구간형 LUT와 양자화가 포함된
실제 함수는 계단형이므로 같은 의미의 정확한 도함수를 사용하지 않는다. 하드웨어에서는 이상적 연속 모델에 대응하는
surrogate gradient (p_hat-y)x_i를 쓴다고 정의한다.

5.2 Cell-level electrical verification
• Write / read / hold: 모든 조합에서 저장 0→1·1→0과 write inhibit 검증; non-selected row read disturb 측정.
• Read bitline: 프리차지 레벨, 방전 시간, 센싱 마진 및 nMOS stack의 누설 전류; RBL polarity 로직이 실제 AND 의미와 같은지
확인.
• Process corners: PDK에서 제공되는 TT/SS/FF 및 온도/전압 corner만 사용. 읽기·쓰기의 실패 corner가 있으면 셀 크기 또는
주변회로를 재설계.
• Layout: 단일 bitcell DRC/LVS/PEX가 통과한 후 배열로 복제한다. read port가 있어도 write disturb와 bitline leakage를
확인해야 한다.

06 정확성 보장 8비트 조기 종료
6.1 왜 근사 아닌 정확한 class가 가능한가
5개의 저장 가중치 W_i를 두 부분으로 분해한다. 음수도 2의 보수 산술 우시프트를 적용해야 한다. R_i의 범위를
[0,255]로 보장하기 때문에 하위 8비트가 MAC의 부호를 뒤집을 수 있는 최대 크기를 계산할 수 있다.
 H_i = W_i >> 8 ; R_i = W_i - 256·H_i , 0 ≤ R_i ≤ 255
 S_H = Σ(x_i·H_i) ; M = Σx_i ; S = 256·S_H + Σ(x_i·R_i)
M은 바이어스를 포함한 활성 항의 개수다. 1≤M≤5. 0≤Σ(x_iR_i)≤255M이 성립한다.
 S_H ≥ 0 → S ≥ 0 → class = 1 (LSB 생략)
 S_H ≤ -M → S ≤ -256M + 255M < 0 → class = 0
위 두 조건을 모두 만족하지 않으면 하위 8비트를 읽어 full MAC을 수행한다. 부호를 추정하는 휴리스틱이 아니라 오차
상계로 증명한 선택적 계산이다. 다만 sigmoid 확률값의 bit-exact 동일성을 의미하지 않는다.

6.3 조기 종료 효과의 조건
성공 시: 해당 샘플의 16비트 전체 읽기에서 8비트만 읽을 수 있다(활성 행별). 실패 시: upper8과 lower8을 모두

07 MAC·Sigmoid·Gradient 회로
7.1 MAC: 조건부 선택 + signed accumulation
입력 x_i가 1일 때만 메모리에서 해당 16비트 가중치에 대응하는 부분곱을 생성한다. 5개 행을 차례로 처리해 19비트
누산기에 더한다. 불필요한 일반 곱셈기는 사용하지 않는다. 가중치의 2의 보수 부호 비트를 포함해야 하며 시리얼/병렬
분할은 실제 면적·지연을 측정해 결정한다.
7.2 Sigmoid LUT: 디지털 회로에서의 비선형 함수
ROM의 x축은 0.25 간격의 k=-32...32이고, y축은 P9=0...256 정수다. 첫 단계에서는 decoder+MUX 또는
transistor-level ROM을 구현해 65개 엔트리 값을 테스트한다. 면적이 지나치게 크면 작은 근사 LUT와 piecewise
approximation을 후속 ablation으로 검토한다. ROM 출력과 class 비교를 혼용하지 않는다.
7.3 오차·SGD 회로
`error = P9 - (y ? 256 : 0)`을 signed 10-bit로 구현한다. 각 x_i가 1이면 16비트 W_i에서 error를 감산하고,
overflow가 생기면 signed 16-bit 범위에 포화시킨다. x_i=0이면 쓰기 워드라인을 열지 않아 불필요한 writeback을
피한다. 이 zero-update gating은 기존에 알려진 최적화이므로 신규성으로 단독 주장하지 않는다.
7.4 Gradient와 ROM에 관한 물리적 가정
정수형 SGD의 학습 곡선은 Python 모델과 bit-exact하게 일치하는지를 검증한다. 디지털 양자화 기울기가 실제
BCE의 연속 미분과 다르다는 사실을 보고서에 명시한다. 학습률 η=1/16은 고정된 실험 조건이며, 이후 1/32, 1/8
등으로 sensitivity analysis를 수행할 수 있다.

• 단일 뉴런이 XOR을 학습하지 못함: 회로 오류로 오판하지 말고 표현력의 한계로 기록하고 4→4→1 확장을 후속 과제로 둔다.
• 전체 칩 Layout 비용이 크면: 검증된 bitcell/macro/critical path만 먼저 PEX, 미완료 블록을 post-layout이라고 부르지
않는다.
