# SRAM-CIM Accelerator

8T SRAM에 저장한 가중치를 이용해 연산과 온칩 학습을 수행하는 회로 설계안입니다.

[설계기획서 PDF](SRAM-CIM%20Accelerator%20Proposal.pdf)

## 구성

- 4개 이진 입력과 바이어스 항, 5개의 16bit 가중치
- Q4.12 고정소수점 연산과 MAC·Sigmoid·SGD 회로
- 읽기 포트를 분리한 8T SRAM 셀과 가중치 저장 배열
- 학습에는 전체 정밀도를 사용하고, 추론에서는 상위 비트부터 읽는 구조

## 비교 항목

전체 16bit를 읽는 기준 구조와 단계적으로 비트를 읽는 구조를 비교합니다. 비교 지표는 분류 결과의 일치 여부, 읽기 에너지, 제어 회로를 포함한 면적과 지연입니다.

PDF는 연구 설계안이며, 성능 측정 결과 보고서는 아닙니다.
